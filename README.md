# FormForge — 汎用Webフォーム自動入力エージェント

ブラウザ内だけで動く Chrome MV3 拡張機能です。拡張アイコンをクリックすると**任意のページ**にフローティングパネルを表示し、**ローカル推論サービス**（OpenAI 互換 + function calling）が DOM ツール経由でフォームを順に埋めていきます —— 実際のプルダウン選択肢を読み取り、バリデーションエラーに合わせて修正し、**確認画面／送信直前で停止します（送信は絶対にしません）**。データはすべて自分のローカル LLM 内で完結します。

## インストール

1. OpenAI 互換のローカル推論サービス（LM Studio / llama.cpp など）を用意し、**function calling 対応**のモデルをロードします。
2. `chrome://extensions/` → デベロッパーモード → パッケージ化されていない拡張機能を読み込む → このディレクトリを選択。
3. フォームページを開く → 拡張アイコンをクリック → 接続設定にサービスの URL とモデルを入力（既定はプレースホルダ `<your-host>:8434`。モデルに `auto` を指定すると利用可能なモデルを自動選択）。
4. シナリオを入力（空欄可）→「自動入力を開始」→ パネルの実行ログを確認。

## できること

- **対応コントロール**：text / number / textarea / リッチテキスト / select（複数選択・リモート） / radio / checkbox / switch / date / file / クリック可能なカード。Ant Design を優先しつつネイティブ HTML にフォールバック。多段ウィザード、長大なフォーム、モーダルフォームに対応。
- **賢さ**：実際のプルダウン選択肢を読む／バリデーションエラーに応じて自動修正（例：カナ欄を全角カタカナへ）／ページ順にひとつずつ入力／失敗しても無限ループせず人手に委ねる。
- **安全性**：`click_button` が最終送信系のボタン（送信・登録・Submit・購入 などの語彙リスト）を強制的にブロック。確認画面では `finish` のみ許可します。

## 注意

- function calling 対応モデルが必須です。長い agentic ループでは小型モデルは不安定になることがあります。
- 入力するのはテスト値です。名称系には「テスト」を付け、メールはプラスエイリアス `local+<tag>@domain` を使用します（ベースメールはパネルで設定可能）。
- ビルド不要でソースをそのまま読み込みます。テストは `test/` にあります。
